Hand & Finger Tracking Module

21-point kinematic hand topology, individual finger pose analysis, and gesture detection

Overview

The Hand module provides precision 21-landmark kinematic hand tracking, per-finger state evaluation (extended, curled, flexion angle), pinching detection, and gesture recognition (fist, pointing, peace, thumbs up, waving).

21 Landmarks

Standardized hand landmark topology across wrist, CMC, MCP, PIP, DIP, and TIP joints for all 5 fingers.

Finger Poses

Detects individual finger states, joint angles, and tip positions for thumb, index, middle, ring, and pinky.

Gestures

Classifies waving, pinching, clapping, raised hands, peace, thumbs-up, and pointing automatically.

Quick Start

from yolozone import HandTracker, PoseDetector
import cv2

pose = PoseDetector("yolov8s-pose.pt")
tracker = HandTracker()

cap = cv2.VideoCapture("videos/hand-gesture-01.mp4")
while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break
    kp = pose.find_keypoints(frame)
    hands = tracker.update(frame, keypoints=kp)
    frame = tracker.draw_tracks(frame, hands, draw_skeleton=True, draw_gestures=True)
    cv2.imshow("Hand Tracking", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
