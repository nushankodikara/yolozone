Object Training Helper Module

Effortlessly create datasets, annotate bounding boxes, and fine-tune YOLO models for custom items

Overview

Adding custom objects to detect has never been simpler. The Object Training helper handles directory creation, automated train/val splitting, YOLO coordinate normalization, data.yaml generation, and one-click model fine-tuning.

Dataset Helper

Automates creation of images/train, images/val, labels/train, labels/val, and standard data.yaml.

Sample Annotation

Add image samples with pixel bounding boxes; automatic conversion to normalized YOLO box format.

One-Click Training

Fine-tune any YOLO model (v8, v9, v10, 11) with a single method call and auto-save best weights.

Quick Start

from yolozone import DatasetHelper, ObjectTrainer

# 1. Initialize dataset
dataset = DatasetHelper("my_custom_dataset", classes=["drone", "package"])

# 2. Add sample images and bounding boxes
dataset.add_sample(frame, [("drone", (120, 100, 240, 180))])

# 3. Fine-tune model
trainer = ObjectTrainer(base_model="yolov8n.pt", dataset=dataset)
results = trainer.train(epochs=30, imgsz=640, device="cpu")
print("Best model saved at:", results["best_weights"])
